## 本轮决策

- 按完整能力拆分为两项需求，不将 IPC/容器文件等技术任务拆成单独需求。
- 宿主机后台服务统一采集，TUI 为本机客户端，Web 为同机独立容器；二者仅消费服务数据。
- 仅内网访问；无登录；程序不管理网段、防火墙或路由策略。
- 历史继续只保留约 60 秒；Web 无回看和平移。此决定覆盖当前 HTML 中 180 秒和平移演示，不改变现有指标的 60 秒计算口径。
- 原 `joi-observer` 命令只连接采集服务，不保留独立采集模式。
- 采集服务未启动或连接中断时，TUI 和 Web 都提示错误、不自动重连；这一限制覆盖浏览器、TUI 及 Web 后台到采集服务的数据通道。
- Web Running/Total 显示真实计数，省略未知容量分母，不新增容量上限配置。
- Web GPU、模型、容器超量时仅显示面板可容纳的条目，其余隐藏；不增加超量滚动、分页或面板扩高，隐藏项继续采集。
- TUI 连接错误后恢复终端、报错退出，重新运行命令才重试；Web 停留错误页，刷新才重试。一个用户刷新恢复共享通道，不应自动恢复其他已报错页面。
- 统一采集配置仅在宿主机采集服务启动/重启时生效，本期不实现热重载。
- TUI 和 Web 均为模型列表显示 name、详情显示 served_model_name；省略 served_model_name 时兼容既有 name 回退，不新增必填字段。Docker 两种界面均显示配置 id。
- REQ-001 保留并复用既有有效测试覆盖，未变更功能的原有测试必须通过。接口迁移或已确认行为变化允许调整、替换相应用例；不得通过删除、跳过或弱化断言掩盖重构回归，新增测试作为补充。对应验收统一为 AC-111。
