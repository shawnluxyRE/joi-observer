## 本轮决策

| 决策 | 结论 |
| --- | --- |
| 产品范围 | 本机全屏 TUI；硬件、指定 Docker、vLLM Chat/Embedding/Reranker；不做 Web 看板 |
| WebUI | 入口禁用，左右键首版不切换；不做占位页或采集 |
| 模型类型 | 三个已部署模型均持续采集和显示：qwen3.8-flash-next、qwen3-embedding-4b、qwen3-reranker-0.6b；名称、类型和直接采集地址可配置 |
| LiteLLM | 不访问或采集 LiteLLM 服务指标，不作为模型项或采集依赖；直接采集三个 vLLM 服务 |
| 分类型指标 | Chat 展示 Token 吞吐、TTFT、KV Cache；Embedding/Reranker 展示完成处理速率与 Avg latency，生成类不适用项省略或 N/A；三类均展示运行/等待、Avg queue、状态及对应吞吐历史 |
| 延迟与单位 | 延迟为最近 60 秒观测加权均值，无观测用 `—`；pooling 计数和计时范围依可靠来源明确，不能把内部序列速率标成 HTTP req/s，不能把引擎内延迟称为完整 HTTP 响应耗时 |
| 主题 | Moonlight/Hologram；只用 t 切换，右上角不可点击；默认 Moonlight，仅会话内保留 |
| 其他键位 | ↑↓ 选择模型并联动 GPU 关联高亮，q 全局退出；无 Details/Pause，方向键不直接选择或滚动硬件区 |
| 模型与 GPU 联动 | 依据显式配置或可靠映射，选中模型关联卡的编号、利用率条已填充段及百分比用主题主色，未关联卡对应位置用灰色；未知映射不显示关联高亮，不猜测；不因模型选择过滤、重排 GPU 或改变布局、采样 |
| 磁盘 | 指定挂载点容量和使用率，默认 `/`、`/data`；仅采集/显示配置前 3 项，超出忽略不报错；Storage 固定 3 行内容，标题/边框另计 |
| 基本行为 | 默认每秒采样、约 60 秒内存历史、失败不伪装为 0、单来源故障隔离、恢复后自动更新 |
| UI 故障展示 | 仅原位显示 STALE；不显示最后成功时间、距今时长、错误原因、堆栈或额外诊断信息，不新增行、弹窗或错误面板 |
| 页面分区 | 主归 REQ-006，核心验收 AC-607；下半区服务窗口、服务切换位和键位提示合计占全页一半，上半区使用余高；REQ-001 的容量判定和 REQ-005 的底部入口共同遵守 |
| Storage / Docker 高度 | Storage 固定 3 行内容，标题/边框另计；Docker 填充右侧余高，按配置顺序仅显示内容区可容纳的容器，剩余隐藏且不作任何提示，内容少时允许留白 |
| 布局稳定 | 固定终端尺寸/配置下，正常、失败、恢复及模型类型切换不改变分区和图表高度；缩放时保持上下各半、Storage 固定，Docker 随剩余高度伸缩 |
| 小窗口 | 低于基础布局所需尺寸时提示放大且保留 q；Docker 容器总数不增加最小高度，仅列表溢出时不触发提示或影响其他面板；不要求适配 80×24 |
| 错误日志 | 并入 REQ-001，只记录采集失败 ERROR，包含时间、来源、对象与原因；不记录正常采样、启动/退出/恢复或 N/A，不在 TUI、stdout/stderr 输出采集日志 |
| 日志配置 | config.yaml 指定目录，默认 `~/.joi-observer/`，文件 error.log；支持 ~ 展开及自定义绝对目录、自动建目录；默认 10 MB（10,000,000 字节）轮转阈值及 3 份备份，均可配置 |
| 日志可写性 | 初始化失败在进入 TUI 前提示一次后继续监控，暂不写日志；运行中失败不打印错误、不改变 TUI、不阻塞采集；恢复可写后记录后续错误，不要求补写丢失记录 |
| 重复错误 | 同一来源、同一对象相同错误首次立即记录，持续失败时至少间隔 60 秒；不同对象或新错误立即记录；恢复后再次失败视为新一轮故障，恢复本身不记日志 |
| 首次配置 | 提供示例 config.yaml，由用户先复制并修改；缺少配置时提示所需路径与示例位置后退出，不使用内置目标直接采集 |
| Docker 状态格式 | 生命周期状态首字母大写、其余小写，例如 Running、Exited、Restarting、Paused、Created、Dead |
| 配置与数量 | Storage 仅取前 3 项、超出忽略；Docker 配置数量不限、全部采集，显示层按当前行数取前若干项，不改配置、不自动发现未配置容器；隐藏项仍采集。Docker 不增加滚动/分页/更多标记，放大后可显示更多条目 |

上述决定优先于设计稿和早先澄清，特别是右上角“按钮”、鼠标点击、WebUI 切换、旧 Details/Pause、早先“仅 Chat”的范围，以及 UI 展示采集时间/原因的旧条款。v1.5 同时取代原先“日志初始化失败就退出”和“每次重复采集失败都记录”的默认规则。Embedding/Reranker 是本期实际采集对象，其指标不能直接照搬 Chat 或模拟稿。错误详情只进入文件日志；真实采集到的容器 Exited 等业务状态照常显示，不当作采集失败。

v1.7 取代早先模型切换不联动上半区及所有 GPU 利用率条统一使用主色的描述；仅联动关联高亮，仍不直接导航硬件区，也不改变其显示对象、顺序、布局或采样。

v1.10 取代“Docker 高度贴合条数、不留空白、余高给 Storage”的旧规则；上下分区比例以全页高度计算，底部服务切换和键位提示不在一半之外另占行。

v1.11 取消 Docker 配置/采集的前 5 项截断及固定上限；v1.12 进一步取代“必须同时显示全部容器、放不下就提示放大”的规则。现在只在显示层隐藏放不下的后续条目，其他区域正常显示且不提示；历史修订中的相关描述仅用于追溯。
